# v0.1 minimum-configuration UX audit

Audited 2026-09-05 against the 59 advertised action operations, the Alert Trigger activation fields, the generated contracts recorded in [api-matrix.md](api-matrix.md), and pinned OSS v0.92.2 behavior. The audit checked required metadata, empty defaults, subtype visibility, locator normalization, pre-transport validation, confirmations, selector dependencies, and sanitized server detail.

| Resource            | Operations audited                                                                                   | Minimum-configuration result                                                                                                                                                                                                                                                                                                     |
| ------------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Stream              | Get Many, Get Schema, Update Settings, Delete Fields, Delete                                         | Targeted operations require a stream locator. Blank schema keyword is intentionally omitted. Settings and delete-fields bodies must be non-empty; Delete requires confirmation.                                                                                                                                                  |
| Log                 | Ingest, Ingest Many                                                                                  | Stream and record inputs are required; executors reject non-object records and empty batches before transport. An empty object remains a valid JSON log event.                                                                                                                                                                   |
| Search              | Query, Get Field Values, Search Around                                                               | SQL/time/range inputs and stream locators are validated by operation. Search Around requires an explicit anchor record containing `_timestamp`, rather than presenting `{}` as usable. Optional filters remain optional; Return All is limited to normalized JSON rows.                                                          |
| Metric              | Instant Query, Range Query, Get Metadata, Get Labels, Get Label Values, Find Series                  | PromQL/label/matcher inputs are required where the endpoint requires them. Time, limit, and positive Prometheus step values are validated; optional filters do not create empty query parameters.                                                                                                                                |
| Trace               | Get Latest, Get DAG                                                                                  | Trace stream and trace ID are required where applicable. Offset/limit/timeouts are validated; read-only operations need no confirmation.                                                                                                                                                                                         |
| Function            | Create, Get Many, Get Dependencies, Update, Delete, Validate VRL                                     | Names and VRL/sample inputs are required by operation. JSON shapes and VRL-only transformation semantics are enforced; Delete requires confirmation.                                                                                                                                                                             |
| Dashboard           | Create, Get, Get Many, Update, Delete                                                                | Folder/target locators and Create title are required. Create has a minimal valid dashboard definition; Update fetches and merges omitted fields; Delete requires confirmation.                                                                                                                                                   |
| Alert Template      | Create, Get, Get Many, Get Prebuilt, Update, Delete                                                  | Names and bodies are required; Email Create additionally requires a visible title while webhook templates do not show an unused title. Updates preserve system classification; Delete requires confirmation.                                                                                                                     |
| Alert Destination   | Create, Get, Get Many, Update, Delete                                                                | Create requires name, template, and URL; webhook URL/header JSON is validated and secrets are redacted. Delete requires confirmation.                                                                                                                                                                                            |
| Alert               | Create, Get, Get Many, Update, Delete, Enable, Disable, Trigger Manually, Clone, Get History, Export | Folder/alert/stream locators are required by operation. Create now requires at least one destination before transport. Pinned OSS accepts the default custom/null query for creation; scheduled-only frequency/look-back fields are hidden for real-time alerts. Delete and manual trigger require separate confirmations.       |
| Pipeline            | Create, Get, Get Many, Update, Delete, Enable, Disable, Get History                                  | Create explicitly requires a complete graph/configuration instead of presenting an empty invalid graph as usable; source/graph shapes and type consistency are validated. Mutation targets must be user-visible. Updates fetch and preserve graph/version. Delete requires confirmation; history time/page inputs are validated. |
| OpenObserve Trigger | Alert Triggered                                                                                      | Folder and selected-alert fields are required. Activation normalizes a non-empty unique alert selection, requires stable workflow identity, and mutates only selected alerts; inbound secret validation precedes workflow output.                                                                                                |

Empty `{}` defaults remain only where they mean “no advanced overrides” and are merged with required friendly fields or a fetched complete object. Optional empty locators/filters are normalized and omitted; malformed locator shapes fail locally with item context. Resource and operation selectors remain expression-disabled, while data fields remain expression-friendly.

The shared error normalizer preserves known HTTP response detail fields (including OpenObserve response data/body), maps the status to a useful n8n error, and redacts credentials, authorization values, URL secrets, and explicitly supplied sensitive destination-header values. It does not copy arbitrary request configuration or telemetry into the displayed error. Runtime behavior can still vary by OpenObserve edition/version; pinned limitations and live evidence remain recorded in [testing.md](testing.md).
